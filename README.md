# Jaya Harish J — Portfolio

A responsive, single-page portfolio site built with plain HTML, CSS, and JavaScript.

## Deploy with GitHub + Vercel

1. Create a new GitHub repository named `jaya-harish-portfolio`.
2. Upload `index.html` and this `README.md` to the repository root.
3. Sign in to Vercel using GitHub at https://vercel.com/new.
4. Import the `jaya-harish-portfolio` repository.
5. For a static HTML site, leave the framework preset as **Other** and leave Build Command and Output Directory empty. The `index.html` file must be at the repository root.
6. Select **Deploy**. Vercel will provide a live URL.

To update the site later, edit `index.html` in GitHub and commit the change; Vercel will redeploy automatically.
